Atividade de JavaScript: Promises e Fetch

Exercício com setTimeout, .then(), fetch() e forEach().

1. Ordem de execução

O JavaScript executa primeiro as instruções síncronas. Depois executa as callbacks das Promises (microtarefas) e, por último, a callback do setTimeout (tarefa), mesmo com atraso zero. O temporizador não interrompe o código que já está sendo executado.

2. Consulta com .then()

A função listarNomesComThen(url) consulta a API, verifica o status HTTP, transforma a resposta em JSON e usa forEach() para mostrar os nomes dos produtos. Ela retorna a cadeia de Promises.

3. Testes

Primeiro é feita a consulta em /products. Em seguida, a página testa /products/0 para verificar o tratamento da falha.

Os mesmos resultados podem ser visualizados no console do navegador (F12).
